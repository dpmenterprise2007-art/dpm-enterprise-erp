# DPM ENTERPRISE ERP

Premium billing, GST, full double-entry accounting, and interior-project management software for DPM ENTERPRISE PRIVATE LIMITED.

## Technology
- Frontend: Next.js + TypeScript
- Backend: Python + FastAPI
- Database: PostgreSQL
- Desktop: Tauri (planned)
- Deployment: local-first with encrypted cloud backup

## Scope
- GST invoicing, estimates, quotations, credit/debit notes
- Customer and vendor management
- Purchase, expenses, inventory and banking
- Double-entry accounting, ledgers and financial statements
- Interior project BOQ, costing and furniture manufacturing workflows

## Security
This is a public source-code repository. Never commit real company financial data, customer/employee records, GST portal credentials, passwords, API keys, bank details, or production backups.

## Status
Initial repository setup. Not production-ready.
